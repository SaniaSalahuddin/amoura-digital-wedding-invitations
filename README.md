## 🌸 About The Project

**Amoura** is a digital wedding invitation website inspired by the beauty and excitement of wedding season.

The project brings traditional wedding invitation aesthetics into a modern digital experience. It focuses on elegant visual presentation, thoughtful design details, and an engaging user interface to make sharing wedding celebrations more special.

Instead of relying only on traditional printed invitations, Amoura explores how beautifully designed digital invitations can provide a convenient and memorable way to share wedding details with family and friends.

## ✨ Features

- **Elegant UI Design:** A visually appealing interface with a romantic and modern aesthetic.
- **Digital Wedding Experience:** A dedicated online space for presenting wedding invitation details.
- **Responsive Design:** Layouts designed to adapt to different screen sizes and devices.
- **Modern Components:** Reusable UI components for a consistent design experience.
- **Interactive Elements:** Smooth interactions and animations to enhance the user experience.
- **Typography & Visual Details:** Carefully considered styling to create an elegant wedding-inspired appearance.
- **Modern Frontend Architecture:** Built using a modern React and TypeScript ecosystem.

## 🚀 Getting Started

Follow these steps to run Amoura locally.

### Prerequisites

Make sure you have installed:

- Node.js (LTS recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/SaniaSalahuddin/amoura-digital-wedding-invitations.git
```

### 2. Navigate to the Project

```bash
cd amoura-digital-wedding-invitations
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 🎨 Design Philosophy

Amoura is built around three design principles:

**1. Elegance**

A wedding invitation should feel special. The design focuses on creating an elegant and visually pleasing experience.

**2. Simplicity**

A clean interface helps visitors focus on the most important details without unnecessary distractions.

**3. User Experience**

A digital invitation should be easy to access, navigate, and experience across different devices.
